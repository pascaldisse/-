### 甲.2 既定済欠陥 (前身 polar.rs, 梯2が継承すれば違反)

- **欠陥-1 (出現律)** `stick_to_polar` は magnitude を無加工返却 → deadzone活性瞬間に r が 0→dz 跳躍。可視/可聴 pop-in。契約 r=0=無 と非連続。
  - 是正: `r = (mag − dz)/(1 − dz)` clamp [0,1]。
- **欠陥-2 (r=0=無)** `atan2(0.0,0.0)=0.0` → 中心で θ=0=+1=愛 を出力。無が愛方位を主張する。下流 (梯3 音·梯4 場注入) は r=0でも θ を受け取り、gate漏れ時に鳴る。
- **欠陥-3 (r上限)** 方形stick領域 → magnitude 最大 √2。amp=r 契約下でclip/過振幅。
- **欠陥-4 (直書)** `22.5` / `45.0` / `8` / `360.0` が hardcode。八家=8 は公理級だが 鉄則の例外は LOVE=1 のみ → param既定つき化 or 律側で明文例外化 (要 Pascal裁定)。
- **欠陥-5 (再生契約)** 梯1 log の `{:.4}` 量子化 → 「同log→同z列」は log を真値源とする限り**原理的に不可**。生値をfull精度 (hex/f32 bits) で併記するか、再生契約を「量子化log基準」と明記するかの二択。

### 乙.2 限界 (正直申告)

- **周波数分解能**: `fs/N_fft` (N_fft=標本数以下最大の2冪, zero-padding不使用). 1.0s@44.1kHz→約0.67Hz, 4.0s→約0.17Hz. 短尺wavほど粗い。内挿値(refined_freq_hz)は主lobe中心の放物線近似で分解能より精密だが**保証誤差ではない**。
- **検出できぬ欠陥種**:
  - θ(音高)の意味論的正しさ (八家/十二平均律写像が契約通りか) は判定不能 — wavは周波数の物理量のみ持ち、どのθから来たかの情報を含まない。
  - エイリアシング/折返し: 標本化された波形から真の入力周波数か高域折返しかは原理的に区別不能。
  - 緩やかなfade (envelope立上り/立下りが数十sample以上に渡る場合) はclick検出の閾値設計上「段差」として拾わない (意図的 — 急峻な不連続のみ捕捉)。閾値=期待最大標本間差分(理論値)×3倍・下限1e-4 — この係数選定はA12「出現律」検出用に調整した値であり一般解ではない。
  - stereoのL/R位相関係・定位は解析対象外 (mono downmixのみで周波数/振幅/包絡/click判定)。
  - 量子化雑音・THD・SNR等の統計品質評価は未実装。
  - 上位3peakまでの探索 — 4本目以降の意図せぬ倍音/ノイズ成分は見逃す。
  - gate/envelope検出はduty=0.5・矩形gateの1ケースのみ校正済。極端に低いduty·非周期envelope·フェード付gateでの挙動は未検証。
