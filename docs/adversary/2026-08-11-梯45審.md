### 乙.1 契約の読み (審側の解釈 — 建側と食い違えば其れ自体が欠陥)
`文書/環統合.md` 音高行より、梯5 は 音 → z の**逆写像**:
```
L = log2(f / 基音)   基音=220.0 (梯3 音高.rs 既定と同値, param)
lap = floor(L)                     ← octave = 巻
frac = L − lap ;  θ = 2π·frac      ← 環位置
家  = round(frac·8) mod 8          ← 八家snap (家数=param)
r   = 音量                          ← 振幅
無  = z=0 ⟺ r=0 ∧ lap=0           ← 丙-C1
連続化は 総角 θ+2π·lap で行う       ← 丙-C3
```
→ **梯3 (z→音) と梯5 (音→z) は逆写像対**である。故に最強の検査は往復 (乙.1-R)。

音高定義のある全件で 実測周波数 − 期待周波数 が解析分解能以内。**注入波そのものは正しい**が独立に立証された (被審へ入れる前に測定器を測った)。非音高信号 (雑音·無音·DC·多声·倍音族) は支配周波数が無意味な為 判定=—、これらは被審のz出力側で r=0契約・確度gate として判定する。

**この具の限界 (正直申告 — 一季 乙.2 を継承)**:
- 分解能 = fs/N_fft (zero-padding無)。2.0s@48k → 約0.37Hz。内挿値は保証誤差ではない。
- 折返しか真の周波数かは標本列からは原理的に判別不能 (C13の判定は被審の宣言paramとの突合で行う)。
- stereo定位·THD/SNR·上位3peak超の成分は解析対象外。
- **本具は「入力が正しい」しか言わぬ。z出力の正しさは 乙.4 で被審log/API から測る。**
