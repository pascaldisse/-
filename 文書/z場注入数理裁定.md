## 1. 総角規約

### 1.1 一意性 (θ+2π·lapが唯一正しい理由)

観測列 θ_n = wrap(φ(t_n)) は真の連続角 φ(t) (未知・巻数込み) の (-π,π] 剰余類代表元でしかない。総角(z_n) = θ_n + 2π·lap_n (z.rs `総角()`, 環注入.rs `総角()`) が真の φ(t_n) の一意な再構成である為には二条件を満たす必要十分:

1. **整合**: 総角(z_n) ≡ θ_n (mod 2π) — 観測値と法2πで一致 (自明: 定義から成立)。
2. **最短歩幅**: 総角(z_n) − 総角(z_{n-1}) = d_n, ここで d_n は θ_n−θ_{n-1} を (-π,π] へ環正規化した主値 (z.rs `変換()`のlap更新ロジックそのもの)。

条件2が**一意**に真のφを再構成する根拠 = 標本間の真の角変位 |φ(t_n)−φ(t_{n-1})| < π という前提 (§1.3のNyquist条件) の下で、法2πのある実数を (-π,π] へ写す主値表現は一意であり、真の変位もその主値と一致する (真の変位がπ未満なら「短い方の弧」以外に真の経路はあり得ない)。故に lap_n = round((φ_n−θ_n)/2π) は一意に定まり、総角は一意な再構成 — z.rs `変換()` の「巻計数は±π横断で符号付き増減」実装はこの一意最短歩幅を毎tickで再帰的に足し込む形。

θ単体 (代表元のみ) を下流で線形補間する方式は条件2を満たさない — 代表元は法2πの等価類の一断片に過ぎず、実数として線形補間する操作自体に数学的根拠が無い。

### 1.2 反例 (±π縫目の不連続, 具体数値)

環注入.rs既存test「総角補間は縫目を連続に越える」と同一入力で示す:
θ_{n-1}=3.1, lap_{n-1}=0 (t=0) → θ_n=−3.1, lap_n=1 (t=1) — 真の動きは+0.0831853…rad (0.4767°) の小さな前進 (2π−6.2=0.08318530717958605)。

**誤 (θ単体・代表元線形補間)**: θ_naive(0.5) = (3.1 + (−3.1))/2 = **0.0** — 円の反対側 (裏側) を通る誤った経路。真の位置との誤差 = |0 − π| = π rad (180°, 最大級の誤差) — 縫目を跨ぐ標本で代表元補間が円の裏側へ倒れる古典的不具合の直接数値化。

**正 (総角補間)**: 総角(a)=3.1, 総角(b)=−3.1+2π=3.183185307179586, 差=0.08318530717958605 (§1.1条件2の主値と一致)。総角(0.5)=3.1+0.08318530717958605×0.5=**3.141592653589793 = π (厳密)**。wrap(π)=π (環正規化: t>半環でなければそのまま故π自身は変化なし) — 縫目をπという単一の連続点として正しく通過。連続性: どちらの側から見ても θ→±π で総角は同じ値πに漸近 (不連続無し)。

### 1.3 総角速度 Nyquist上限

標本間隔 Δt=1/f_s (f_s=標本率, 機関/環制御では `poll_hz`, 既定60.0 — 機関/環制御/src/main.rs:61, src/z主.rs:64)。§1.1の一意性条件「標本間の真の角変位 < π」を速度で書くと:

ω_true · Δt < π ⟹ **ω_max = π·f_s (rad/s)**、回転数換算で **f_max = f_s/2 (rev/s)** — 標本定理そのものを「角位置という信号」の最大瞬間周波数へ適用した形 (半周/標本が上限、Nyquist周波数=f_s/2と同型)。

既定 poll_hz=60.0 (機関/環制御/src/main.rs:61) → ω_max=π×60=188.49555921538757 rad/s、f_max=**30.0 rev/s**。環注入::Param の `最大回転毎秒` 既定値 = **30.0** (環注入.rs:203付近default, main.rs:558-567 `環param()`)。両者一致 — 文書/環統合.md 丙-C3「実測閾例30rev/s」の根拠がここで閉じる (code側既定値と数式導出が数値一致、環統合.md要求済の相互検証を満たす)。

注意: `最大回転毎秒` はf_sから独立したparamとして環注入::Paramに存在する (main.rs `--環最大回転毎秒`引数) — poll_hzが変更された場合は最大回転毎秒=poll_hz/2へ追従更新する契約が必要 (現状は別々のCLI引数、自動連動なし)。**UNVERIFIED**: 呼び出し側 (機関/環制御→ログ→機関/宇宙) がpoll_hz変更時に最大回転毎秒を自動整合させているかは未確認 — 現状は運用者が二箇所を手動で揃える前提と読める。

## 2. 場保存則

環注入.rs `環波::寄与()` (行179-206) を基準式とする:
strength(q,t) = clamp(A/N, 0, `最大正規化振幅`) × edge(q,t) × 包絡(t)
edge = exp(−(distance−front)²/(2·`波幅`²)), front = 年齢×`波速`, 年齢=今−生時
包絡 = 生起(年齢/`生起緩和秒`, [0,1]) × 終息((寿命−年齢)/`終息緩和秒`, [0,1])、寿命=`射出周期秒`×`slot数`

かつ A/N = (z.r × `振幅利得` × 場norm) / max(場norm, f32::MIN_POSITIVE) = z.r × `振幅利得` (場norm>0で厳密に約分, 環注入.rs:187-191) — norm自体の絶対値に依らずratioはz.r×振幅利得に固定。z.r ∈ [0,1] (Z変param `r上限`既定1.0, z.rs)。故に clampの手前で既に A/N ≤ `振幅利得` — 既定振幅利得=1.0 < `最大正規化振幅`=4.0 の下ではclampは常時不発火 (実効上限は振幅利得自身)。

### 2.1 絶対有界性 (射出周期に非依存, 恒久成立)

`注入器` はslot数固定のring buffer (環注入.rs:236 `slots: vec![環波::無(); param.slot数]`, 行245 `i = (...).round() % slots.len()`) — 蓄積・積分ではなく**上書き**。故に任意時刻tで場に寄与するripple数は常に ≤ `slot数` (射出周期の長短に依らない、構造上の上限)。edge≤1, 包絡≤1 (両者とも[0,1]clamp/exp≤1) を併せ:

**shell(q,t) = Σ strength_j ≤ slot数 × min(振幅利得, 最大正規化振幅)** — main.rs:2106-2109で`shell += strength`(環経路)そのものを積む為、この式がそのままshellの絶対上限。
既定値代入: 8 × min(1.0, 4.0) = **8.0** — 射出周期をどれだけ縮めても (0.5s/2Hzでも, 1kHzでも) この天井は変わらない。**発散はslot数固定ring buffer構造から構造的に不可能** — 期間param不等式は不要 (「T>0なら常に成立」が正しい答え)。

displacement (main.rs:2100-2104, q[0]+=d[0]/distance×strength等) も同一strengthを使う為: **|Δq| ≤ slot数 × min(振幅利得, 最大正規化振幅) = 8.0** (既定)。

対比 (経路A, `wave_gain`はclampの**外側**で別掛け, main.rs:2093-2096): shell_A ≤ slot数×`最大正規化振幅` (gain含まず) = 8×4.0=32.0、displacement_A ≤ slot数×最大正規化振幅×`wave_gain` = 8×4.0×0.12=**3.84** (既定, wave_gain既定=main.rs:477)。経路A/Bはgainの掛かる位置が違う (Bはclamp前, Aはclamp後) — 数値が違って当然、混同禁。

r=0 (無, z.rs `無()`) では A=z.r×振幅利得=0 → `寄与()`冒頭 `self.amplitude==0.0` で即 (0,0,[0,0,0]) — 無は場に何も注がない (§4表 case16で確認)。

### 2.2 清浄重畳条件 (局所ピークが単一波を超えない為の分離条件)

§2.1は「爆発しない」の証明であって「見た目/局所値が単一波の設計上限を超えない (=隣接波が建設的に重なって局所超過しない)」は別命題。同一発生源から周期T (=`射出周期秒`) で連続射出される波は、速度`波速`=c一定の同心波面群となり、隣接世代の波面間隔 = **Δ = T·c** (等間隔, 生成時刻がkT刻みの為)。

幅σ (=`波幅`) の等高Gauss二峰が「中点で互いの単峰高さを超えない」臨界間隔は半値全幅 (FWHM) 則から:
**Δ_crit = 2√(2·ln2)·σ ≈ 2.3548200450309493·σ**
(導出: 二峰和 2h·exp(−Δ²/(8σ²)) ≤ h ⟺ exp(−Δ²/(8σ²))≤1/2 ⟺ Δ²≥8σ²ln2 ⟺ Δ≥σ√(8ln2)=2σ√(2ln2) — 標準FWHM公式、独立検算可)

**清浄重畳条件: T ≥ 2√(2ln2)·波幅 / 波速**

既定値代入 (環注入.rs既定: 波速=4.2, 波幅=0.11, main.rs既定射出周期秒=0.5 [--環射出周期秒, main.rs既定値と後述]):
T_min = 2.3548200450309493 × 0.11 / 4.2 = **0.06167385832223915秒**
既定 射出周期秒=0.5秒 (**=2Hz**, 課題文の想定と一致) → 安全率 = 0.5/0.06167… ≈ **8.11倍** — 現行既定値は清浄重畳条件を約8倍の余裕で満たす (UNVERIFIED表現ではなく本裁定内で導出・再計算済の数値)。

経路A (frame単位, GEOMETRY_WAVE_SPEED=0.035, GEOMETRY_WAVE_WIDTH=0.11) では T_min = 2.3548200450309493×0.11/0.035 = **7.400862998668698 frame**。2Hz (0.5秒周期) をframe換算するには実測fps (§0のUNVERIFIED事項) が要る — 条件は f_fps_実測 ≥ 2×7.400863 = **14.80 fps** で満たされる。現行到達fpsが未計測 (`w.set_target_fps(0)`実測依存) の為、経路Aでの2Hz射出が清浄重畳条件を満たすかは**UNVERIFIED** (妥当な描画負荷なら大差で満たす見込みだが、実測ログ (proof=fps実測log) が無ければ成立と書けない)。

不等式に現れる5変数の関係まとめ: **slot数と振幅利得(gain)は絶対天井 (§2.1, 期間非依存) を決め、射出周期・波速・波幅は局所ピーク超過の有無 (§2.2, FWHM分離) を決める** — 単一の5変数不等式に強引に統合すると意味が薄まる為、二つの独立命題として書く方が正確 (数学鐘の判断)。

### 2.3 補足: slot利用効率 (必須条件ではない, 参考)

恒等式確認 (環注入.rs:181, 245): 寿命=射出周期秒×slot数=生時+寿命で世代k+slot数の射出時刻と厳密一致 — スロット上書きと寄与打切りが同時刻で一致する設計 (継ぎ目・重複無し, 再現可能な代数恒等式、param非依存で常に成立)。
既定値での有効視認時間 (概算, edge無視できる距離+3σ通過): domain半径R_domain (立方grid仮定, grid_coordinate正規化で最大コーナー距離=√3≈1.7320508075688772, field_w=field_h=field_dのUNVERIFIED仮定) → 通過時間≈(R_domain+注入半径)/波速=(1.7320508+0.5)/4.2≈**0.5314秒** に対し寿命=8×0.5=4.0秒 — スロットは寿命の約13%のみ視覚的に意味を持ち残りは無寄与のまま保持 (害は無い=§2.1の絶対有界性は不変、設計効率の余地はあるが**必須条件ではない** — 誤って「発散阻止条件」と混同しないこと)。R_domain実測 (実際のfield_w/h/d既定値) は未確認 — **UNVERIFIED**、代表値として立方grid仮定を明記。

## 3. lap→shell写像

式: `depth = clamp(z.lap × shell刻, −1.0, 1.0)` (環注入.rs:183附近, main.rs `環shell刻`既定=main.rs:480 → 0.25)。

**妥当性**: z.lapは環注入.rs `Z列::場()` で線形補間される実数 (z.rs側は整数だが、環注入.rs `Z標本.lap: f64` として補間対象 — 環注入.rs:87 `lap: a.lap + (b.lap - a.lap) * 割`) — 段差なし連続量。depthの値域[−1,1]は grid_coordinate() (main.rs) が生成するx,y軸の正規化値域と同じ[−1,1]系 — 単位系が空間座標と整合 (次元不一致無し)。

**単調性**: shell刻≥0 (main.rs assert「--環shell刻 must be finite and >= 0」) が保証される限り、clamp∘線形写像は**弱非減少 (weakly monotone non-decreasing)** — 常に成立。shell刻>0の時は開区間 lap∈(−1/shell刻, 1/shell刻) 上で**狭義単調増加**、区間外は定数 (次項)。shell刻=0は退化 (常にdepth=0, 単調性は自明に保たれるが情報量ゼロ)。

**飽和 (|lap|大)**: 既定shell刻=0.25では |lap| ≥ 1/0.25 = **4.0** でdepthは境界値±1へ飽和 — 4.0回転を超える巻数差は区別不能 (非単射, clampの意図された挙動: 物理的shell層の最外殻/最内殻を超えて動けないという設計意図と整合、故に「妥当」だが情報損失は明記すべき仕様)。飽和開始点ちょうど (|lap|=4.0) は未飽和側の値と一致 (連続, 段差無し — §4 case4/5/6で確認)。

**UNVERIFIED**: 実運用でstickを振った際に到達する典型|lap|の分布が測定されていない — 4.0回転という飽和閾が実用域に対し狭すぎる/広すぎるかは未検証、本裁定は数学的妥当性 (連続・単調・単位整合) のみを保証する。
