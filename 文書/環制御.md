# 環制御 — DualSense→場 制御界面 (08-11)

系譜: 三bit方位環 (todo §) + 歌語 + iPod環洞察 → stick=極座標native。
機: PS5 DualSense ↔ Mac (Bluetooth/USB · Apple GameController framework 或 SDL2 — 実装時選択param)。

## 公理
制御=場への波紋注入。button=離散op · stick/trigger=連続場。中央春=無への自動帰還 — 手を離す=fold to 000。

## 配置

### 左stick — 方位環 (主移動)
- 角度 atan2(y,x) → 8扇形×45° = 八家/八卦 (000=mmm…111=aaa、todo §三bit方位環)
- 押幅 hypot → 大きさ (0=中央=無)
- 連続mode (param): 扇形snap切、生polar注入
- 回転検出 → lap計数 = 螺旋高度
- L3押込 = 000強制 (void錨)

### 右stick — 第二卦
- 左右二卦合成 = 6bit = 64卦 = 道 (向き+次の向き) — 場の軌道指定
- 或 (param): 観測核方向 = 縮約視点操舵 (camera=fold方向)
- R3押込 = 視点reset

### L2/R2 — 愛争op対 (analog圧)
- R2圧 = 愛op (収束·引力·振幅注入) — 錬金術.md §愛争
- L2圧 = 争op (分離·斥力·減衰)
- adaptive trigger抵抗 = 場密度feedback (書きながら読む)

### 触pad — formant平面 (歌語直結)
- 2D touch = (F1,F2) vector — 母音空間 (歌語.md表: /a/=(730,1090)…/i/=(270,2290)) — 指=音色、場への記号overlay座標
- 二指 = 和声 (重ね合わせ二波)
- pad押込 = om (無への収縮op)

### 面button — temple verb (七↔七環, 錬金術.md)
- ✕ = CREATE (溶解) · ○ = DESTROY (焼成) · □ = WITNESS (分離) · △ = BIND (合一)
- L1 = REFLECT (蒸留) · R1 = INVOKE (発酵)
- options = DREAMSCAPE (凝固→1) · share = 場snapshot (proof出力)

### gyro — 三次元Einheitsvektor
- 実傾き = 場の重力方向 或 三軸生vector (param) — 手が空間を指す

### 帰路 (場→手)
- haptics = 場振幅@手元 — 既定律動2Hz (生命搬送波、歌語§) · 波紋到達=触知
- speaker = 場の音 (縮約→audio核)
- 灯bar = 場状態色 (vector→色、縮約教義)
- mic = 歌語入力 — 声→pitch/formant抽出→場op。歌で場を書く=最終界面

## 実装梯
1. 読取: SDL2或GCController → stick/trigger/pad生値 print (接続証明)
2. 橋: 生値→場op変換 (方位環snap · 愛争圧 · formant座標) — 機関/宇宙 への注入口
3. 帰路: 場振幅→haptics (2Hz既定) + 灯bar色
4. 歌路: mic→pitch/formant→歌語op (較正儀式=話者param)

法: 全定数=param既定値つき (鉄則) · 出現律=連続注入、pop禁 · proof=映像+入力log。
