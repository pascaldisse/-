## 〇．基本律

- **一問一独立clean lane**。一laneは**問を一つだけ**受ける。電池混載（十五問同lane）を禁ずる。rev.1 の「一電池一lane」「一lane一電池」は**廃止**（差戻①）。
- 測定lane の任務文は **目盛規約 ＋ 実問一個 ＋ 回答形式** のみ。rev.1 の「問番号列のみ」は**問本体が欠落**しており誤り、廃止（差戻①）。
- 同一問の反復は **N≥5 の独立lane**。同一召内の RUN1〜5 は同文脈反復であり独立ではない（弾劾一）。
- **族均衡**：各族の lane 数を等しく置く。族結論は **lane≥2/族**（弾劾二）。四族 × 2 → **実効最小 N＝8**。N5 は族均衡と両立しない（差戻②）。
- **盲検**：測定lane は仮説・先行値・軸名の評価語を見ない（§五）。
- **全対禁**：語彙 N≈2000 の全対＝約200万問。軸射影＋層化標本対で代替する。

### 目盛規約（測定lane任務文の冒頭へ一字一句同文で置く）
- 距：〇＝同一、十＝無関係。
- 軸(A↔B; C位?)：**A端＝〇、B端＝十**、中点＝五。
- 序：与えた候補のみを近い順に並べる。追加語を禁ずる。
- 類：語一つ。
- 答形式：`答: <値>` の一行のみ。説明・前置き・後書きを禁ずる。

## 三．軸選抜規準（差戻③：全て試走前登録の暫定gate）

**本節の閾値は試走前に登録された暫定値であり、測定後に動かした場合は改定履歴を残す。校正は held-out 語で行い、試走語で閾値を再当てはめしない。**

- **分離度**：頑健散布度で測る。**IQR** および **MAD**（`max-min` は外れ値依存ゆえ主指標から外す。参考値としてのみ併記）。暫定gate：語間射影値の族内中央値分布で **IQR ≥3**。
- **一致度**：族間中央値差の **bootstrap CI**（BCa・2000再標本）。暫定gate：差の 95%CI 上限 ≤3 の語が過半。
- **族内再現性**：同族 lane 間の分割半信頼性（split-half）／級内相関 ICC。暫定gate：**ICC ≥0.5**。これを満たさぬ軸は族間比較の資格を持たない。
- **冗長判定**：軸対の **Spearman ρ ＋ bootstrap CI**。殺すのは **CI下限 ≥0.85 が試走語で成立し、かつ held-out 語でも再現した場合のみ**（同一試走語だけでの殺しを禁ずる／差戻③）。
- **残す側の規準**（冗長対で生き残る軸の決め方・事前登録）：①ICC が高い方 ②IQR が大きい方 ③形式逸脱率が低い方。三項の順に適用し、同点なら**両方残して未決とする**（恣意的な片殺しを禁ずる）。
- 極性反転（初式Q11/Q12）が目盛規約明示後も残るか否かを、軸ごとに必ず記す。

## 四．軸端対照（差戻④：数と設計の訂正）

rev.1 の「288対」は誤記。実体は **288 距問 ＝ 144 A/B対照組**（各組＝ 距(A,C) と 距(B,C)）。

- **lane配置**：距(A,C) と 距(B,C) は**別lane**。同laneで両方を訊かない（同lane比較は片方の答が他方の文脈になる）。
- **導出量**（事前定義）：`P̂(C) = 10 × d(A,C) / (d(A,C) + d(B,C))`。分母0は欠測。
- **符号規約**：A端＝〇。よって `P̂` は軸問の射影 `S(C)` と**正**の対応を持つはず。負相関が出れば極性規約の破れとして第一級に記録する。
- **合格閾**（事前登録）：`P̂` と `S` の Spearman ρ ≥0.6 かつ CI下限 >0。未達＝その軸の射影は**測器由来の疑い**として UNVERIFIED。
- **held-out C**：軸選抜に未使用の語のみを対照に使う（選抜と検証に同じ語を使わない）。
- **端間距 d(A,B)**：各軸で必ず測る。暫定gate **≥7**。端が近い軸は軸として退化しているので殺す。
- **負対照**：①無縁対（期待 8〜10）②同義／準同義対（期待 0〜2）。この二つが期待帯を外す lane 群は測器不良として当該batchごと破棄。
- **順序 counterbalance**：距(A,C)／距(C,A) を半々、軸(A↔B)／軸(B↔A) を半々に割る。順序効果・極性効果を推定量として取り出す。
- **共有失敗の明記**：距問と軸問は **同一模型群・同一〇〜十尺度**を共有する。よって両者の一致は「独立検算」ではなく**同一失敗様式の再現**でありうる。この限界を各表の脚注へ必ず書く。
- **第三経路の実配置**：尺度を使わない **序問**（順位のみ）を実際に走らせる。軸ごとに held-out 5語を候補として `序(A: C1…C5)` を N8 で測り、軸射影順との **Kendall τ** を報告する。三経路（軸・距・序）の一致／不一致を判定表へ載せる。

## 四'．回転protocol（断層撮影法・Pascal親令）

**原理**：単一文脈の battery は多様体の**一射影**でしかない。全図は射影を**基底を回して**繰り返し集め、逆投影で復元する（Radon／CT。疎な角度からの復元＝compressed sensing）。同一概念対を**別基底で**測ることは、同一問の反復とは別物である。反復は分散を測り、**回転は形を測る**。

### 回転軸（基底変換の種類）
軸の命名は **ROADMAP 準拠**：`language` · `persona` · `framing` · `temperature` · `head`。

| id（正名） | 記号 | 水準 |
|---|---|---|
| `language` | L | DE・JA・EN・ZH（M1基底＝EN・M2で DE/JA/ZH へ回転） |
| `persona` | P | 裸の頭 / 魂付き小道 |
| `framing` | F | poetic（詩的）/ clinical（臨床）/ narrative（物語） |
| `temperature` | T | 低 / 既定 |
| `head` | H | 族（claude・kimi・glm・jareth 等・M2で naru-* へ拡張）——**既に族均衡＝N8 の次元**であり回転係数へ二重計上しない |

回転cell ＝ (`language`,`persona`,`framing`,`temperature`) の一組。密格子 4×2×3×2 ＝ 48cell。

### M0 gate（ROADMAP 準拠・本段階の合格条件）
**pilot が v1 錨を ≥2基底下で再現すること**。錨は二つ、事前登録の帯で判定する：

| 錨 | v1値（非独立・参照のみ） | M0 合格帯（事前登録） |
|---|---|---|
| 距(愛,無) 遠 | 7〜9 | 各基底で 族中央値 **≥6**（下限のみを問う） |
| 軸(生↔死; 夢) 中点 | 5[3-6] | 各基底で 族中央値 **4〜6** |

- **基底＝回転cell**。「≥2基底」は最小4pass のうち**少なくとも二つの cell で独立に**帯を満たすことを意味する（全pass合算での達成は不可）。
- 各基底で 1問1clean lane・N8・族均衡を満たす。争域枝（軸の極性反転等）は **反復十**（ROADMAP M0）。
- **不合格の意味**：v1 錨が再現しないことは失敗ではなく所見である（v1 は非独立反復・尺度規約なしで取られた）。しかし **M1 へは進めない**：錨が崩れた場合は測器側の不具合を先に特定する（目盛規約・訳文同値・逸脱率）。

### 最小回転（承認必須条件・差戻追補⑤）
- **同一概念問につき 4 pass を必須とする**：言語2（日・英）× framing2（臨床・詩的）。これを下回る設計は本計画として承認されない。
- 各 pass は**独立projection**。各 pass 内で **1問1clean lane・N≥5（実効 N8）・族均衡**を個別に成立させる。pass をまたいで N を数えない。
- **意味同値の事前固定**：訳文と framing 变体は測定開始前に確定し、`prompts/` へ版管理して凍結する（sha256 登録）。測定中の文言修正を禁ずる。同値審査は**測定lane とは別の盲検lane**が行う（審査者は仮説を見ない）。
- 測定lane へは既結論・期待方向・**他 pass の答**を一切見せない（§五）。

### 記録列（必須）
`language_id` / `frame_id` / `pass_id` / `lane_id` / `model族` / `raw`（生応答文字列）/ `清浄`（規格化後の値・逸脱は null）。付属：`prompt_sha256` / `order` / `逸脱理由`。生応答は**必ず保存**する（清浄値のみを残すことを禁ずる）。

### pass 別集計と pass 間一致度
- **pass 別**に中央値[幅]（主指標は IQR、max-min は併記）・lane数・族内訳・逸脱率を出す。pass をいきなり合算しない。
- **pass 間一致度は問型ごとに別指標**：
  - 数値問（距・軸）：pass 別中央値の **ICC(2,1)** と Spearman ρ＋bootstrap CI、並びに **Bland–Altman 偏差**（pass 間の系統的ズレ）。
  - 序問：**Kendall τ** と **首位一致率**。
  - 類推問：**完全一致率** と **Fleiss κ**（答を事前定義の類へ写す、写像規則も事前登録）。
- 判定：pass 間が一致＝**基底不変の構造**（地形候補）。不一致＝**座標系の癖**。両方を残す。不一致を誤差として平均で潰すことを禁ずる。

### held-out 回転 pass
- 4pass のうち **1pass を held-out** として保留する（例：英×詩的）。軸選抜・閾値校正・冗長判定に **使わない**。
- 用途：①軸選抜結果の検証（生存軸が held-out pass でも分離度gateを満たすか）②独立検算（§四の軸端対照を held-out pass でも走らせ、合格閾を同一に適用）。
- held-out で崩れた軸・関係は **pass 依存**として格下げし、屍と因を残す。

### 疎抽出（compressed sensing）——最小4pass の**上**へ積む場合
- 最小4pass は常に張る。それを超える回転（中・独・物語・温度・persona）は密格子を張らず、各項目へ **追加 k 個**を割り当てる（v4 段階）。
- 割当は **balanced incomplete block**：各回転水準が**項目30個以上**に現れるよう釣り合わせる（水準効果を推定可能にするための下限）。割当は種固定の擬似乱数＋均衡検査、種と手順を記録する。
- 各 (項目 × cell) につき **N8 独立lane**。回転はNを置換しない。

### 各passの扱い
- 一つの回転cell の測定群＝**一つの独立projection**。pass ごとに座標表 `v_r` を出す。
- 蓄積：pass集合 {v_r} から多様体を復元する（射影の逆投影／低ランク近似）。復元結果を `M_k`（k＝取り込んだpass数）とする。
- **収束指標**：`M_k` と `M_{k-1}` の Procrustes 距離。暫定gate（試走前登録）：**連続二回 <0.05** で当該領域を「鮮明」と判定。未達なら pass を足す。
- 回転で**動く**関係と**動かない**関係を分ける。動かない＝基底不変の構造（真の地形の候補）。動く＝座標系の癖（言語・framing の効果）。**両方をデータとして残す**。争域を平均で潰さぬのと同じ理由で、回転差を誤差として潰さない。
- 言語回転は `README.md` 次路二「言語横断等長検」の実装であり、別企画ではない。

### 版格子（v-lattice）
| 版 | 内容 | 判定 |
|---|---|---|
| v1 | 無回転・粗図（初式 battery-v1 相当） | 全て暫定・非独立 |

### 遮断との両立
- 回転cell の識別子（L/P/F/T）は **sidecar のみ**に置く（§五）。測定lane は自分が何の回転かを知らない。
- framing 回転は**問の言い回し**を変えるが、目盛規約の文言は不変（〇＝同一・十＝無関係・A端〇）。目盛が回ると射影ではなく単位が変わり、復元不能になる。
- 言語回転では目盛規約も当該言語へ訳す。**訳文は事前に固定し版管理**する（訳のゆらぎを回転効果と取り違えないため）。

## 五．遮断規約（差戻⑤）

- 禁止（manifest に現れてはならない）：既結論・先行値の数字・仮説・軸の評価語（「普遍」「争域」「膨張型」等）・他頭の答・**他 pass の答**・**自分が何の回転 pass かという識別子**・期待方向・本書 plan-v2 そのもの。
- **design doc 非読込**：測定lane は `README.md`／`plan-v2.md`／`battery-*.md` を読まない。設計文書は統率lane のみが読む。
- **lane metadata は外部 sidecar**：軸ID・run番号・族名・順序条件は lane 外の sidecar（`manifest/*.json`：`{lane_id, prompt_sha256, axis_id, run, family, order}`）で管理し、prompt 本文へ書かない。
- **検証**：発射前に prompt を禁止語表と突き合わせる自動検査を通す。事後は `prompt_sha256` で改竄検出。
- **汚染lane は破棄**（結果を採らない）。屍と因を残す。

## 九．未驗（本計画自体の弱点）

- §三・§四の全閾値（IQR≥3・CI上限≤3・ICC≥0.5・ρ≥0.6・d(A,B)≥7・冗長CI下限≥0.85）は**試走前登録の当て**であり、測定値ではない。校正は held-out で行い、改定は履歴を残す。
- 族が正しい統制単位かは未決。初式は分散が **lane 粒度**に宿ると示した。段二で lane内分散 vs 族間分散（ICC）を比較して初めて判る。
- 12,408 lane（縮退案・N8）の実費は**未測**。段〇の単価表が出るまで段一を承認しない。
- 序問（第三経路）が本当に尺度共有を免れているかは未検証。順位も同一模型の同一前処理を通る。
- 層化抽出の配分比（核×核偏重）は情報量最大化の仮定。未測。
- **回転protocol の中核仮定＝「別基底の測定は独立な射影である」は未検証**。言語・framing を回しても同一模型の同一前処理を通る以上、射影が縮退している（全角度が同じ影を返す）可能性がある。段一の回転感度（v2）が最初の反証機会。
- Procrustes 収束閾 0.05・水準あたり項目30・k=2 は全て**試走前登録の当て**。
- 27,936 lane（回転込み・N8）の実費は未測。段〇の単価表に**回転cellごとの単価差**（言語別トークン長・framing別逸脱率）を含めて初めて査定できる。
