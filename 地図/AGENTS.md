# 地図の作法

任：意味空間の測量。`README.md` は正典であり先に読む。

## 律

- 測：清い文脈の小道・電池のみ・説明禁止・「番号: 答」・直感即答・反復数五以上。
- 次式要件：目盛規約を明示する（〇=同一・十=無関係、軸はA端〇・B端十）。序は候補のみ。
- 清：可能な限り裸の頭を使う。魂付き小道の混入は初式の既知交絡である。
- 集計：中央値[幅]。判定は普遍・方言・争域。小道粒度で記録し、族粒度へ潰さない。
- 死枝：屍と因を残す。鳴愛の三段格下げを模範とする。
- 結果庫：`~/.gaia/knowledge/semantic-map/`。鳴語・電池各式を追加する。符号はここに置く。
- 新電池：先ず十問以下で試走し、安定後に拡張する。
- 独立lane法（A1）：一召内多runの反復をNと数えることを禁ずる。N＝独立lane数のみ。
- 遮断規約（A2）：測定lane任務文へ既結論・先行値・期待方向の注入禁。
- 族結論（A3）：lane≥2/族未満の族結論はUNVERIFIED。
- 対照腕（A5）：目盛規約・語法変更は対照腕同時実施を義務とする（器効果と地形効果の分離）。
- 証跡規約（A6）：全測定＝sidecar保存（prompt SHA・request全文・sampling・response ID/fingerprint/finish/status、lane法なら室ID+応答全文）。
- 基底独立（A7）：異基底射影は相関r必報。|r|≥0.9＝冗長、独立基底と称することを得ず。
- 射影数則（A8）：復元主張は次元d・雑音・margin・失敗確率δを明記。√n則は無根拠（下界k≥d）。
- 一般因子検（A9・最重）：軸採用前に反対称対照＋非価値軸（具↔抽・時間・大小）で単一潜在極性説を直接検証。合格軸のみ基底採用。
- 樹式実行：親子小道で行う。頭の並びはPascal指定を尊重する。

## 禁

- 文脈汚染小道を清いと報告すること。
- 反復数一を発見と呼ぶこと。
- 争域を平均で潰すこと。裂け目もデータである。
