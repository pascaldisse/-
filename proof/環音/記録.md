## 検算 (独立経路: python numpy FFT + 零交差 — 我がGoertzelと別実装)
- `環音_掃引.wav` 尾部 (掃引域): t=15.5s **370.6Hz** (期待 220·2^{6/8}=370.0) · t=17s **402.8Hz** (期待 403.5=家7) · t=19s **219.7Hz** (家7→家0折返し=期待220) → 八家梯子一致 (FFT分解能 ±1.5Hz)。
- `環音_無律動.wav`: t=1.0s 219.7Hz (lap=0·家0=基音220) → 以降 111→76→55Hz と**下降**。
  - 原因判明 (誤りに非ず): proof/環制御/入力log.txt の実stickは**時計回り** → 甲規約 (±π横断で巻増減) により lap −3..0。独立にlogを再解析し lap範囲 −3..0 を確認 → 220·2^{−2}=55Hz と実測一致。器は入力に忠実。
- 律動gate: 既定 2Hz·開率0.5 → `環音_八家.wav` は約0.25s毎に無音区間 (RMS窓で確認済)。
