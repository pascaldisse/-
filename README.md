# 愛無

愛無・場・場語の作業殿。各小殿は成果枝を独立記録として保持する。

## 構え

- `場語/`：場語本体・組立・審査。
- `機関/`：無の内在・世界・零段。
- `場/`：場基盤の容量・核・決定性・記録・性能・平面・世界・統合・零段・針。
- `実験/`：第二配線。
- `文書/`：八連憲章。

各小殿は枝先を留める子殿である。履歴は各子殿の記録と魔晶殿の枝に存する。

## 魔晶殿

魔晶殿本体は別殿であり、ここへ移さない。所在は固定しない。必要時は環境変数 `魔晶殿` に本体の絶対経路を置く。

```sh
export 魔晶殿=/任意の魔晶殿
cd "$魔晶殿"
git worktree list
```

子殿の遠隔先は魔晶殿の正典遠隔先である。初回取得時は子殿を更新する。

```sh
git submodule update --init --recursive
```

## 門

各変更前後に対象小殿で状態確認を行う。

```sh
git status --short
```
